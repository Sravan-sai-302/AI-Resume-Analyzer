# AI Resume Analyzer

## About the Project

AI Resume Analyzer is a Python application built using Streamlit that helps users analyze their resumes and understand their resume content.

## Technologies Used

* Python
* Streamlit
* PDF Processing

## Features

* Upload a resume
* Extract resume text
* Analyze resume content

## How to Run the Project

### 1. Install the required packages

```bash
pip install -r requirements.txt
```

### 2. Run the application

```bash
streamlit run app.py
```

## Project Objective

The objective of this project is to build a simple application that helps users analyze resume content using Python.
